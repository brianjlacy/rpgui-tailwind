# RPGUI Tailwind

Welcome to **RPGUI Tailwind** - a Tailwind CSS UI Kit with retro RPG-style components.

## About

RPGUI Tailwind is a modern reimplementation of the classic RPGUI framework using Tailwind CSS.
It provides pixel-art styled UI components perfect for creating retro gaming interfaces,
fantasy-themed web applications, and nostalgic user experiences.

## Features

- **Tailwind CSS Native**: Built entirely with Tailwind utilities
- **TypeScript**: Full type safety and IDE support
- **Accessible**: WCAG 2.1 AA compliant components
- **Customizable**: Easy theming via CSS custom properties
- **Framework Agnostic**: Works with any JavaScript framework

## Getting Started

```bash
# Install the package
pnpm add rpgui-tailwind

# Import in your project
import 'rpgui-tailwind/css';
```

## Components

Browse the sidebar to explore all available components:

- **Containers**: Frames and content containers
- **Form Controls**: Buttons, inputs, checkboxes, etc.
- **Selection**: Dropdowns and lists
- **Typography**: Headings, paragraphs, links
- **Decorative**: Dividers, icons, cursors
